# web/ 出所台帳

配信用の画像素材。すべて `tools/make_icons.py` が Pillow の図形描画のみで生成した
自作素材(外部素材・フォントラスタライズ不使用・決定論生成)。

意匠は**ヘッドフォン(聞く)がスクリーン(見る)を抱え、その面の上で本文の行と音の波形が並ぶ**形。
`deck.json` の時間軸に `content.json` の本文が乗る、という構造をそのまま図にしている。

| ファイル | 内容 | マークの倍率 |
|---|---|---|
| logo.svg | **意匠の正典**(48x48・配信しない設計ソース)。印刷・外部提出用 | — |
| icon-192.png / icon-512.png | PWAアイコン(通常) | 1.00 |
| icon-maskable-512.png | PWAアイコン(maskable) | 0.95 |
| apple-touch-icon.png | iOSホーム画面用(180px・非透過) | 0.95 |
| icon-32.png | ファビコン。**中身を省き線を1.9倍にした簡略版** | 1.00 |

倍率1.00は、確定意匠の生成画像そのままの余白の取り方(48の枠に対してマークが69%)。
maskable は円形マスク(中央80%の円)に収めるため0.95にしてある
(実測: 中心からの最遠192px / セーフ半径205px・はみ出し0画素)。

再生成: `python tools/make_icons.py`

## 線の細さは意匠の要

線幅は確定した意匠を画素単位で実測した値(ヘッドバンド1.35 / イヤーカップ1.05 / スクリーンの面0.98 /
波形のバー0.66、いずれも48座標系)。**小さいサイズで読みにくいからといって太らせない。**
細い線と13本の波形が意匠そのもので、太らせると別のロゴになる(一度やって差し戻した)。

小サイズは簡略版で受ける。位置と輪郭はそのままに、線幅を **1.9倍**(`SIMPLE_BOOST`)にし、
面の中身(本文の行と波形)を省く。適用先はファビコン(16〜32px)と
カバーのプレースホルダ(44px以下・`player.html` の `glyphSmall`)。

## 同じ形が3か所にある

Pillow・SVG・DOM で描画系が違うため、同一の形を3か所に写している。**変更時は3か所とも直すこと。**

| 場所 | 用途 |
|---|---|
| `web/logo.svg` | 正典。座標の基準 |
| `tools/make_icons.py` の `draw_mark()` | PNG生成 |
| `web/player.html` の `I.glyph` / `I.glyphSmall` | ログイン画面のマーク / カバーのプレースホルダ |

`logo.svg` は**サーバの配信allowlistに入れていない**(`server/kikimiru_server.py` の
`WEB_ALLOWLIST`)。SVGは同一オリジンでのスクリプト実行経路になりうるため、実行時に不要な
ものは配信しない方針に合わせた。実行時に使うのは PNG と `player.html` 内のインラインSVGだけ。

**READMEの見出しには `logo.svg` ではなく `icon-192.png` を使っている。** `logo.svg` は
`prefers-color-scheme` で色を切り替えるが、GitHub上でその CSS が効く保証がなく、落ちた場合は
ライト用の濃色(`#232019`)がダークテーマでほぼ見えなくなる。地色を焼き込んだPNGなら
どちらのテーマでも同じに見えるため、そちらを採った。SVGへ戻す場合は、GitHubの
ライト/ダーク両方で実際に表示を確認すること。

## 配色

`player.html` のダークテーマのトークンに一致させている。

| 役割 | 値 | player.html のトークン |
|---|---|---|
| 地 | `#131519` | `--bg` |
| ヘッドフォンと面の中身 | `#e7e3da` | `--ink` |
| スクリーン(枠・レール・引き手) | `#6ea4dc` | `--tint` |

`logo.svg` だけは `prefers-color-scheme` でライト側(`#232019` / `#2f6093`)へ切り替わる。
PNGは地色を焼き込むためダーク固定。
