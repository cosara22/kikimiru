## 再撮影の条件

サーバをデモライブラリで起動し、各画面を同解像度で撮る。掲載中のものと揃える条件:

- テーマは**ダーク**(`localStorage` の `kikimiru.theme` を `dark` にする。OS設定には従わない)
- 進捗は `localStorage` の `kikimiru.pos.demo/<id>` に注入する。
  形式は `player.html` の `savePos` と同じ `{t, d, at, s, n}`
  - `demo/demo-guide-1`: `{t: 18, d: 42, s: 3, n: 7}`(残り 0:24・スライド 3/7)
  - `demo/demo-audio-lab`: `{t: 35, d: 35, s: 5, n: 5}`(聴了)
- `at` は固定値にする(`Date.now()` だと撮影ごとに表示が揺れる)
- player.png はスライド表示にする(`localStorage` の `kikimiru.npTab` を `slide`)。
  さらに**再生を開始してから撮る**こと。スライド表示の操作オーバーレイは再生中のみ
  2.6秒で自動的に消える仕様で、停止したまま撮ると再生ボタンが本文の上に重なる
  (Chromium は `--autoplay-policy=no-user-gesture-required` で起動し、
  `audio.play()` を呼んでから4秒ほど待つ)
- サーバをスクリプトから起動する場合、**標準出力をパイプのまま放置しない**。
  リクエスト毎のログでパイプバッファが埋まり、サーバが write でブロックして応答しなくなる
  (実測。ファイルか `DEVNULL` へ逃がすこと)
