# デモ素材の出所台帳

公開物に含まれる素材は、すべて出所をここに記録する(release_gate の必須条件)。

| ファイル | 出所 | 権利 |
|---|---|---|
| `library/demo-book/audio.mp3` | `demo/make_demo.py` が ffmpeg の正弦波(sine)のみで合成 | 自作・第三者素材なし |
| `library/demo-book/deck.json` / `content.json` | 本アプリの自己解説として書き下ろし | 自作 |

規律: 第三者の著作物(書籍・楽曲・録音・TTS音声)をデモに使う場合は、
パブリックドメインまたは明示的に許諾された素材に限り、この台帳へ出所と根拠を追記する。
