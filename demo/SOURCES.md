# デモ素材の出所台帳

公開物に含まれる素材は、すべて出所をここに記録する(release_gate の必須条件)。

## 生成方法の共通事項

`demo/library/` 配下の全ブックは `demo/make_demo.py` が ffmpeg のみで生成する。
第三者の著作物(書籍・楽曲・録音・TTS音声・画像素材・フォント埋め込み)は一切含まない。

- **音声** — lavfi の正弦波(`sine`)を区間ごとに生成し `concat` で連結。音声合成(TTS)も
  実演奏も使わない
- **表紙** — lavfi の `gradients` / `drawbox` / `drawgrid` のみで描く幾何学画像
  (512x512 / RGB / PNG)。外部画像も画像ライブラリ(Pillow等)も使わない
- **画像スライド(v2.1・demo-audio-lab の `slides/*.png`)** — 表紙と同じく lavfi の
  図形のみで描く幾何学画像(1280x720 / PNG)。文字描画・外部素材なし。各画像の内容は
  content.json の `alt`(セマンティックレイヤー)にテキストで併記している
- **本文(content.json)** — kikimiru 自身の使い方の解説として書き下ろし。
  架空の書籍の内容を創作したものではない
- **書誌情報(著者・話者・シリーズ名)** — すべて**架空**。実在の人物・団体・書籍・作品を
  指すものではなく、ライブラリ画面(著者一覧・シリーズ一覧・カバーグリッド)の
  表示確認のためだけに置いた見本である

## ファイル別

| ファイル | 出所 | 権利 |
|---|---|---|
| `library/*/audio.mp3` | `demo/make_demo.py` が ffmpeg の正弦波(sine)のみで合成 | 自作・第三者素材なし |
| `library/*/cover.png` | `demo/make_demo.py` が ffmpeg の lavfi フィルタ(gradients / drawbox / drawgrid)のみで描画 | 自作・第三者素材なし |
| `library/*/deck.json` / `content.json` | 本アプリの自己解説として書き下ろし(書誌情報は架空) | 自作 |

規律: 第三者の著作物(書籍・楽曲・録音・TTS音声・画像)をデモに使う場合は、
パブリックドメインまたは明示的に許諾された素材に限り、この台帳へ出所と根拠を追記する。
架空の書誌情報についても、実在の書籍・著者・作品を想起させる名前は使わない。
